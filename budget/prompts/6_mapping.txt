One record per programme
If this strategy is funded by several programmes this year, output SEVERAL records - one per

Matching - substance, not keywords
Match on objective / implementation mechanism / beneficiary group / sector-policy alignment.
Hierarchy (use the highest available): exact programme > exact policy-reform > same mechanism
> same objective > same beneficiary > same sector/policy area. Note that a programme's NAME may
be worded differently from year to year - match on substance, using this year's wording.

Overhead - DO NOT force-match
A budget programme below MAY carry a programme_class, decided by a separate pass that read the
budget alone and knew nothing about this strategy. The column is present only where that pass
has run and matched, so where it is absent, or blank on a row, judge the programme on its
substance by the same four descriptions. Where it is there, use it:

  overhead           finances no policy at all: debt service, pensions, contingency,
                     refunds, internal administration, general management, treasury
                     services. NEVER match one of these, unless this strategy is itself
                     explicitly about that administrative function (a public debt
                     management strategy may match a debt programme; a rural electrification
                     strategy may not).
  standing_function  the state doing what it always does at the scale it always does it:
                     existing salaries and operating costs, routine delivery, maintenance,
                     formula entitlements. Match one ONLY where the strategy is genuinely
                     about running or maintaining that existing service. Do NOT attach a
                     standing function to a strategy that proposes something new, expanded
                     or reformed: the money is already committed to the existing service and
                     the plan is not what directs it.
  development        the discretionary policy budget. Match freely on the substance rules
                     above.
  mixed              treat as development, but only where the strategy's substance is a
                     clear fit; do not reach.

The class is the budget's own character, not a judgement about importance. A large, essential,
popular standing function is still not something the plan chose.
