# Adjudication log

Two checks fed this log. (1) An independent second coder placed a stratified 10% sample (45 objectives) blind: same family 87%, same node 76%, same depth 78%. (2) The sibling test: an objective at L3 is challenged when a sibling mechanism's cue also matches its label, variants or definition (exclusion clauses removed).

Each decision is a worked example for the node definitions.

## Lesson for the coding rules

The first pass went to L3 when one variant of an objective named a channel. The second coder stopped at L2 when the definition as a whole spanned two siblings. The second reading is the rule: depth is set by the whole commitment, not its most specific variant. Rule 2 now reads that way in the build (the sibling test runs on every L3 placement and the build fails if a challenged L3 is not in this log).
